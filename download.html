How to Install

1

Download the ZIP

Click the button above. If your browser warns you about the file, click Keep to save it.

2

Extract the ZIP

Right-click the ZIP and choose Extract All. Put the folder on your Desktop or anywhere easy to find.

3

Run the EXE

Double-click Network Unity Chat.exe. If Windows SmartScreen appears, click More Info then Run Anyway.

4

Update the App Anytime

Double-click Updater.bat whenever you want the latest version. It replaces the old app automatically.
