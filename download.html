How to Install

1

Download the ZIP

Click the download button above. If your browser warns you, click "Keep" to save the file.

2

Extract the ZIP

Right-click the ZIP and choose "Extract All". Put the folder somewhere easy to find, like your Desktop.

3

Run the EXE

Double-click Network Unity Chat.exe. If Windows SmartScreen appears, click "More info" then "Run anyway".

4

Update Anytime

To update the app, double-click Updater.bat. It downloads the latest version and replaces the old one automatically.
