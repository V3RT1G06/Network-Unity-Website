2

Put it anywhere

Move Afterspace.exe to any folder where you want to keep it.

3

Run the EXE

Double-click Afterspace.exe. Windows might show a blue SmartScreen popup — scroll down to see how to handle it.

4

Updates happen automatically

When a newer GitHub release exists, Afterspace downloads the new EXE, verifies GitHub’s SHA-256 digest, keeps a rollback copy, replaces itself, and restarts.

Why does Windows warn you?

The first time you open the app, Windows may show a blue screen saying “Windows Protected Your PC.” This is not a virus warning — here is what it actually means.

Why SmartScreen fires

Not a malware scan — a certificate check

SmartScreen flags apps that don’t have a code-signing certificate from Microsoft. Afterspace is currently unsigned, which is common for free and independent tools.

SmartScreen does not scan the file for malware. It only checks whether the developer paid for a certificate. The warning says nothing about whether the app is safe.

How to run it anyway

Two clicks
  • When the blue popup appears, click More info — small text below the main message
  • A Run anyway button appears at the bottom — click it
  • The app opens. Windows only asks this once

Verified automatically. GitHub publishes a SHA-256 digest for the release asset. The app checks that digest and the EXE’s Afterspace version metadata before replacing your current copy.
